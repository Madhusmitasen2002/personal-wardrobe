#  Personal Wardrobe & Outfit Planner

A clean, easy-to-use digital closet that helps you organize the clothes you own and puts together outfit ideas based on the daily weather.

---

##  Live Website

- **Website:** [personal-wardrobe-fawn.vercel.app](https://personal-wardrobe-fawn.vercel.app)
- **API Server:** [personal-wardrobe.onrender.com](https://personal-wardrobe.onrender.com)

---

##  What It Does

1. **Digital Closet:** Upload photos of your clothes. The app automatically cuts out the background so your closet looks clean and organized.
2. **Category & Tagging:** Sort items by tops, bottoms, shoes, jackets, and accessories by season and color.
3. **Weather-Based Outfits:** Shows local temperature and suggests what to wear (e.g. layers for chilly mornings, light fabrics for hot days).
4. **Mix & Match Studio:** Pick and pair items together to see how an outfit looks before you put it on.
5. **Secure Accounts:** Sign up and log in securely so your wardrobe is private to you.

---

##  Tech Stack

- **Frontend:** React, Tailwind CSS, Vite
- **Backend:** Node.js, Express
- **Database:** MongoDB Atlas
- **Image Storage:** Cloudinary
- **Hosting:** Vercel (Frontend), Render (Backend)

---

##  Running Locally

### 1. Clone the project
```bash
git clone https://github.com/Madhusmitasen2002/personal-wardrobe.git
cd personal-wardrobe
```

### 2. Run Backend
```bash
cd backend
npm install
npm run dev
```

### 3. Run Frontend (in a second terminal)
```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.
